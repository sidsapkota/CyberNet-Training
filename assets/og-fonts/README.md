# Fonts for link-preview images

IBM Plex Sans (regular and semibold, Latin subset, WOFF) for `src/lib/og.tsx`, which renders the
Open Graph and Twitter images at build time. The image renderer needs raw font files, so they
live here rather than coming from `next/font`.
